# Инструкция по развёртыванию My Cloud на reg.ru

## Быстрый старт (3 шага)

### 1. Подготовка сервера

1. Создайте виртуальный сервер на reg.ru:
   - **Тариф:** Минимум 2 ГБ RAM, 2 ядра CPU, 40 ГБ SSD
   - **ОС:** Ubuntu 22.04 LTS
   - **Регион:** Москва

2. Подключитесь к серверу:
   ```bash
   ssh root@ваш_ip_адрес
   ```
